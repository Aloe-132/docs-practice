# Quick Start Guide: Creating a Private Repository on GitHub

## Objective

To create a private repository with a README file on GitHub.com.

## Prerequisites

- A GitHub account
- A desktop browser
- A stable internet connection
- Permission to create a repository
- An existing project or a topic for documentation

## Steps

1. **Open GitHub**  
   Visit https://github.com in your desktop browser and sign in to your account.

2. **Start a New Repository**  
   Click the “+” icon in the upper-right corner and select “New repository” from the dropdown menu.

3. **Enter Repository Details**  
   Type a suitable name for your repository in the “Repository name” field. You may also add a short description to explain its purpose.

4. **Set Repository Visibility**  
   Select “Private” under the repository visibility options. This ensures that only you and authorized collaborators can access the repository.

5. **Add a README File**  
   Check the box labeled “Add a README file.” This file provides basic information about your project and serves as a starting point for future documentation.

6. **Create the Repository**  
   Click “Create repository” at the bottom of the page. Wait for GitHub to finish creating your repository.

## Result Check

The repository is successfully created if its homepage displays the repository name, a “Private” label, and a README.md file with its content. You can now edit the README and add project files.

## For Later Use

Keep the repository link for future reference. You can use this repository to store project documents, organize files, and collaborate with others.
