# Create a Private Repository with a README

## Goal

Create a private repository in your personal GitHub account with a README file.

## Before you start

Sign in to GitHub.com in a desktop browser with the English interface. Use your personal account and have a repository name ready. This guide creates a new repository; it does not change an existing repository.

## Steps

1. Open the **+** menu in the upper-right corner.
2. Select **New repository**.
3. Choose your personal account as the owner.
4. Enter `docs-practice` in **Repository name**. If that name already exists in your account, enter a different name.
5. If you want to explain the repository's purpose, enter a short description.
6. Select **Private** for the repository visibility.
7. Set **Add README** to **On** to initialize the repository with a README file.
8. Select **Create repository** and wait for the repository page to open.

## Result check

Confirm all three results on the repository page:

- The owner is your personal account and the repository name matches your entry.
- The repository has a **Private** label.
- The file list contains `README.md`, and its content appears on the repository page.

## If it fails

If GitHub displays a validation error, correct the indicated field and select **Create repository** again.
